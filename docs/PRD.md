# 拾页 · Shiye Tab

## 产品目标
把 Chrome 新标签页变成自己的信息看板。打开即可看到值得读的内容，数据源、顺序、分类由用户决定。参考附件的浅色多列卡片，不复刻其品牌。

## 首版范围
- Manifest V3 扩展直接替换新标签页，无账号、无服务端、无遥测。
- HowToLiveBetter：每次打开随机读取一条，支持换一条，保留章节、原文与授权归属。
- GitHub Trending 周榜：使用官方周榜顺序、仓库描述和本周新增星标，不用搜索 API 代替。
- 国内 iPhone 免费总榜 Top 10：七麦卡片支持接入用户有权使用的 JSON 接口；七麦无法直连时明确提示。另提供明确署名的 Apple 官方榜单卡片，不能冒充七麦。
- 自定义 RSS / Atom / JSON Feed / 通用 JSON 数据；newsletter 通过发布者的 RSS 或用户自己的邮件转 RSS 服务接入。
- 添加、编辑、移除、拖动排序、按钮排序、分类过滤、搜索当前内容；浅色/深色/跟随系统；2/3/4 列；配置导入导出。
- 逐卡刷新、缓存、失败提示、原文跳转；更新失败保留旧内容并标记旧缓存。

## 数据与隐私
配置和内容保存在本机。内置源仅访问指定域名，自定义源在保存时请求对应站点权限。内容仅按文本呈现；禁用脚本 URL，不执行远端代码。配置导出可能包含私有订阅地址，导出前界面提示。

## 验收
扩展加载后新标签页显示看板；源连接异常不显示伪造内容；新标签页随机内容变化；配置刷新后仍存在；添加 RSS 和 JSON 可读取条目；错误/空内容/无权限有明确区分；通过实际 Chromium 扩展运行和界面操作验证。

## 后续
邮件 OAuth 接入、跨设备同步、可选自托管聚合服务、更多官方数据适配器。本版不读取邮箱或浏览历史。
