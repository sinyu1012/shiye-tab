# 验收记录

## 开源整理（2026-10-09，Asia/Shanghai）

本次整理包括紧凑布局、石墨与钴蓝配色、图标居中、本地 HTTP 白名单、单条阅读卡片、订阅摘要换行、移除默认七麦占位卡片，以及 README、许可证和商店资料。

### 可复现检查

- `npm run check`：全部应用模块语法检查。
- `npm test`：配置导入安全边界和随机不重复抽样。
- `npm run build`：仅复制扩展运行必需文件到 `dist/`。
- `npm run test:extension`：隔离 Chromium profile，使用固定测试响应，验证真正的 Manifest V3 扩展页面。
- `git diff --check`：检查补丁空白错误。

本轮执行结果见下方最新验证结果。固定响应测试不证明上游实时可用，也不代表个人 Chrome 的权限已授予。

### 扩展回归覆盖

- `chrome://newtab` 跳转至扩展页面；默认三张卡片，没有未配置的七麦占位卡片。
- 生活建议换条与重新打开后避开上一条。
- 深浅主题、列数持久化，分类与品牌首页入口，按钮和拖动排序。
- RSS 与 JSON 添加、删除、重新打开后保留；RSS / Atom / JSON Feed 解析及嵌套字段映射。
- feed HTML 不执行脚本，过滤危险 URL；HTTP 503 时显示旧缓存及失败原因。
- 配置导出、导入往返；非法配置拒绝导入且保留原配置。
- 桌面顶栏 64px、卡片起点 88px、常规卡片高 520px；1920、1024、768、390px 无横向溢出。

### 既有功能专项验证（2026-10-08）

以下为此前实现阶段的运行记录，不应视为本轮重新执行：

- 单条 RSS / JSON 使用阅读卡片；条数 1 → 3 → 1 切换与刷新持久化，搜索不会触发错误的布局切换。
- 摘要保留 `<br>`、段落、CRLF 和 JSON 文本换行，标题仍合并空白；缓存版本切换后重新抓取。
- 具体白名单内的局域网 HTTP 源，在实际扩展和站点授权后读取成功。
- 真实网络曾读取 HowToLiveBetter 原文、GitHub 周榜、Apple 中国免费榜；网络与上游内容仍会变化。

### 数据与发布边界

七麦需要有权访问的 JSON 接口，不内置可用榜单服务，不绕过签名或验证码；Apple 榜单为独立来源。自动化不会加载个人 Chrome profile。测试输出、个人配置、临时订阅数据及 ZIP 包不纳入 Git。

商店首次提交审核的历史记录见 [发布资料](../store/RELEASE.md)。提交源码、推送 GitHub 和商店发布是不同步骤，本轮不重新上传商店包。
